## 🌟 Overview

A modern, responsive, high-performance single-page portfolio website designed with visual excellence, retro-futuristic skeuomorphism, and an emerald green cyber accent. Fully self-contained in a single lightweight `index.html` with zero external dependencies or heavy frontend frameworks.

### ✨ Key Features
- **The Portfolio Console Hardware Hero**: An interactive skeuomorphic hardware deck with 3D mechanical keycaps, springy bounce physics (`cubic-bezier(.22,1.5,.4,1)`), tactile Web Audio API click feedback, and an idle wave animation.
- **Mobile Tactile Control Deck**: Dedicated 3D mechanical hardware controller for mobile viewports (<768px and <480px) with comfortable 52px touch targets, spring click animations, and tactile audio.
- **Mobile Optimized Experience**: iOS Safari input auto-zoom prevention (`font-size: 16px`), zero horizontal scroll overflow (`overflow-x: hidden`), clamp line-wrapping on terminal text, and touch-optimized navigation.
- **Dynamic Terminal Screen in Lid**: Real-time monospace terminal display typing out interactive contextual information as you hover or tap mechanical keys.
- **Core Specialty: AI Automation & Agentic Workflows**: Highlighting autonomous multi-step AI agents, Model Context Protocol (MCP) integrations in Python, n8n webhook workflow pipelines, and in-situ automated computer vision inspection.
- **Interactive Project Filter Bar**: Filter projects dynamically across `All Projects`, `⚡ AI Automation`, `Computer Vision`, `Generative AI`, and `Web / Mobile` with multi-category matching.
- **Continuous Credibility Marquee**: Sleek status strip showcasing Autonomous AI Agents & n8n automation, IIT Jammu defect detection, IJCOT publication, honors degree, and computer vision / GenAI credentials.
- **Direct PDF Resume Access**: Download or preview the full official resume (`resume.pdf`) directly from the navbar, keycap console, hero section, and contact card.
- **Dynamic Role Typing**: Interactive role cycling (`AI Automation & Agentic Engineer`, `Computer Vision Developer (YOLOv8 & OpenCV)`, `Generative AI & n8n Specialist`, `Machine Learning & Edge AI Engineer`) with immediate recruiter action items.
- **Technical Skills Matrix & Specialty Banner**: Comprehensive categorization covering Autonomous AI Agents, MCP, n8n, Computer Vision (YOLOv8, OpenCV), ML & Deep Learning, and Databases/Tools.
- **Engineering Philosophy & In-Browser Resume Preview**: Showcasing an automation-first mindset ("My strength is my laziness" — automating repetitive workflows) paired with an instant in-browser modal preview and direct download options.
- **Fully Responsive & Accessible**: Optimized for desktops, tablets, and mobile devices with smooth scroll-spy navigation and `prefers-reduced-motion` compliance.

## 🚀 Live Preview & Deployment

### View Locally
Simply clone the repository and open `index.html` in any browser:
```bash
git clone https://github.com/gow1n-d/gowind_portfolio.git
cd gowind_portfolio
start index.html  # On Windows, or open index.html directly
```

### GitHub Pages Setup
To deploy this portfolio live for free via GitHub Pages:
1. Navigate to your repository on GitHub: `https://github.com/gow1n-d/gowind_portfolio`
2. Go to **Settings** > **Pages** (under the "Code and automation" section).
3. Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
4. Select branch: `main` and folder: `/ (root)`, then click **Save**.
5. Your portfolio will be live at `https://gow1n-d.github.io/gowind_portfolio/` within 1-2 minutes!
